# One detail pane that follows the selection

**Goal:** the `field ui` window has one detail region, driven entirely by
the current selection. Clicking a clip brings up its editing surface
there (trim, gain, fades, pitch, and timing) with no menu in between,
and the region shows an empty state instead of a close button.

No plan yet. Picked on 2026-08-20 from
[daw-features §2](../daw-features/readme.md) ("One detail pane that
follows the selection"), which records why: Ableton's single pane is
loved, and Logic's open-and-close editors are the counterexample. The
UI's insert panel ([ui §6](../ui/readme.md)) is the first thing that
region shows. Write the plan here when the work graduates.
