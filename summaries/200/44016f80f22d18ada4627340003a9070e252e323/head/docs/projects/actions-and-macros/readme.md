# Everything is an action, and actions compose

**Goal:** every Field verb is an action in a searchable index, named
macros of actions are committed to the project, and the user can bind a
shortcut to any action. These are all three parts of REAPER's action
system.

No plan yet. Picked on 2026-08-20 from
[daw-features §6](../daw-features/readme.md) ("Everything is an action,
and actions compose"), which records the scope and why Field is most of
the way there: every action is already a CLI verb, and the generated
index is also most of what [mcp-surface](../mcp-surface/readme.md) needs
to describe itself. Write the plan here when the work graduates.
